# PC Remote — краткая инструкция

Полная инструкция находится в корневом [README.md](../../README.md).

1. **Настройки → Устройства и службы → PC Remote** добавляет саму
   интеграцию, но не связывает Windows-компьютер.
2. Привязка запускается в панели **PC Remote** в боковом меню Home Assistant и
   только в браузере на нужном Windows-ПК.
3. Голосовое управление настраивается в этой же панели: **PC Remote → Алиса**.

Для Алисы требуется установленный `Yandex.Station Intents`. В панели есть два
режима:

- **Настройка в панели** — имя ПК для Алисы, включённые действия и фразы
  редактируются формой;
- **Ручной YAML** — безопасный редактор YAML для интентов только PC Remote.

В разделе **Аккаунты Яндекса** один найденный аккаунт выбирается автоматически.
Если аккаунтов несколько, отметьте разрешённые в панели. Сгенерированный YAML
записывает этот выбор в `accounts` каждого интента, поэтому остальные связанные
с Home Assistant аккаунты не смогут выполнить сценарий. В ручном YAML поле
`accounts` всё равно контролируется и перезаписывается выбором из панели.

Для выключения, перезагрузки и их подтверждения используйте режим `websocket`
в Yandex.Station Intents. В режиме `device` нет идентификатора колонки, поэтому
PC Remote намеренно не выполняет опасные голосовые действия.

Перед первой публикацией голосовых команд подтвердите кнопку **Подготовить
голосовую конфигурацию**. Интеграция подключит packages через:

```yaml
homeassistant:
  packages: !include_dir_named packages
```

и будет владеть только файлом
`<config>/packages/pc_remote_voice.yaml`. Существующие интенты пользователя не
изменяются. После настройки нажмите **Применить и синхронизировать**.

Выключение и перезагрузка, включая варианты с таймером, требуют отдельного
подтверждения в течение 15 секунд:

```text
подтверждаю действие с <имя для Алисы>
отменяю действие с <имя для Алисы>
```

Не заменяйте их общими «да/нет/отмена»: эти слова могут уже использоваться
другими автоматизациями Home Assistant.
