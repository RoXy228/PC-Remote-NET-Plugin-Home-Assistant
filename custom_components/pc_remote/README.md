# PC Remote — краткая инструкция

Подробная инструкция находится в корневом [README.md](../../README.md).

Важно: **Настройки → Устройства и службы → PC Remote** добавляет интеграцию,
но не связывает компьютер. Pairing запускается из панели **PC Remote** в левой
боковой панели Home Assistant и только в браузере на нужном Windows-ПК.
